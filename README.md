# ClockNoteWidget — 时钟 + 便签 + B站粉丝 桌面小组件

Windows 桌面小工具，包含**三个完全独立的窗口**：

- **时钟窗口**：时:分（可选秒）+ 日期星期，数字/表盘双模式，每秒刷新
- **便签窗口**：多条便签的新建/编辑/删除/撤销/置顶/颜色切换，自动保存，重启恢复
- **B站粉丝窗口**：显示你的 B 站账号**涨粉数 / 掉粉数（分开统计）**、总粉丝数、今日净变化

三个窗口各拖各的、各记各的位置，互不影响。无边框、半透明、可置顶、不占任务栏，托盘常驻。

> **隐私约定**：程序默认**完全不联网**。只有你在粉丝窗口里主动粘贴自己的 B 站 `SESSDATA` 后，才会向 `bilibili.com` 发起请求，且只请求这一个域名、不上传任何本地数据。凭证与数据只存本机 `%APPDATA%`，不写进源码、不进 Git 仓库、无遥测、无云同步。（v0.6.0 起新增此唯一联网功能）

## 运行（开发模式）

需要 Node.js（建议 18+）：

```bash
npm install --registry=https://registry.npmmirror.com --cache ./.npm-cache
# 若 electron 二进制下载失败，手动补一次：
cd node_modules/electron && ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node install.js && cd ../..
npm start
```

## 日常使用

| 操作 | 方式 |
|---|---|
| 移动窗口 | 按住窗口顶部 36px 拖动条空白处拖动（按钮、输入框、便签正文不会触发拖动） |
| 隐藏单个窗口 | 窗口右上角「✕」（只是隐藏，托盘可再唤回） |
| 显示/隐藏/退出 | 右键（或左键）任务栏托盘蓝色圆点图标 |
| 置顶开关 | 托盘菜单 → 「始终置顶」 |
| 透明度 | 托盘菜单 → 「透明度」（60% ~ 100%，对三个窗口同时生效） |

**关闭窗口 ≠ 退出程序**。退出只能通过托盘菜单 → 「退出」。

## B 站粉丝窗口（v0.6.0 新增）

### 首次配置

1. 浏览器登录 **bilibili.com**
2. `F12` 打开开发者工具 → **应用 / Application** → **Cookies** → `https://www.bilibili.com`
3. 找到 `SESSDATA`，复制它的值
4. 粘贴到粉丝窗口的输入框 → 点「保存并刷新」

窗口只显示掩码（如 `a1b2****wxyz`），**完整凭证不会回显、不会离开本机**。点 ☰ 设置面板可「重新粘贴」或「清除」凭证。

### 数据口径（重要）

| 显示项 | 来源 | 说明 |
|---|---|---|
| 涨粉 / 掉粉（分开） | 创作中心 `member.bilibili.com/x/web/index/stat` 的近 30 天数据 | **T+1，次日中午才更新**，所以窗口显示的是「最近有数据那一天」并在下方标注日期。B 站不提供实时的当日分项 |
| 总粉丝数 | 创作中心 + 公开接口 `api.bilibili.com/x/relation/stat` | 实时值 |
| 今日净变化 | 公开接口每 10 分钟采样粉丝总数 | = 当日首次采样基线之后的净增减（只有净值，分不出涨/掉）；基线当天有效，重启保留 |

未配置凭证时窗口只显示配置引导，**不发任何网络请求**。刷新频率：启动一次 + 每 10 分钟自动 + 点 ↻ 手动。

### 凭证安全

- 凭证存 `%APPDATA%/ClockNoteWidget/fans-config.json`，缓存存 `fans-cache.json`，两者均被 `.gitignore` 排除
- 主进程只把**掩码**和数值发给渲染层，完整 SESSDATA 从不经过页面
- 更换凭证会清空旧账号缓存，避免串号
- 凭证等同于账号登录态，请勿分享、请勿把该文件提交到任何仓库

## 数据与位置记忆

- 窗口位置：三个窗口分别保存 x/y 到 `window-state.json`，重启还原；越界（如换显示器后坐标在屏幕外）自动回到主屏可见区域
- 时钟偏好（模式、12/24 制、秒、表盘大小/刻度/指针色）与便签内容、颜色：存在各窗口的 localStorage
- 粉丝凭证与缓存：见上节
- 全部为本地文件，删除 `%APPDATA%/ClockNoteWidget/`（安装版）或 `%APPDATA%/clock-note-widget/`（开发版）即可彻底清空数据

## Windows 打包步骤

用 electron-builder 生成安装包（NSIS 安装版）和免安装 portable 版：

```bash
# 1. 安装打包工具（一次性）
npm install --save-dev electron-builder --registry=https://registry.npmmirror.com --cache ./.npm-cache

# 2. 打包（x64，输出到 dist/ 目录）
npm run dist
```

构建配置已写在 `package.json` 的 `build` 字段。产物：

- `dist/ClockNoteWidget Setup 0.6.0.exe` — 安装版，可选安装目录、创建开始菜单快捷方式
- `dist/ClockNoteWidget 0.6.0.exe` — 单文件便携版，双击即用

> 打包时 electron-builder 需下载 Electron 发行包，国内网络建议设置环境变量：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`（Windows PowerShell: `$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"`）

## 开机自启说明

本项目未内置自启开关（避免静默写注册表），如需开机启动，任选其一：

**方法 1：启动文件夹（推荐，免安装版同样适用）**

1. `Win + R` 输入 `shell:startup` 回车，打开当前用户启动文件夹
2. 把应用快捷方式放进去：
   - 安装版：右键开始菜单里的 ClockNoteWidget → 打开文件位置 → 右键快捷方式 → 复制，粘贴到启动文件夹
   - 便携版：右键 `ClockNoteWidget 0.6.0.exe` → 显示更多选项 → 发送到 → 桌面快捷方式，再把桌面快捷方式剪切到启动文件夹

**方法 2：任务管理器**

任务管理器 → 启动应用 → 找到 ClockNoteWidget（安装版才会出现在这里）→ 右键启用。

取消自启：从启动文件夹删除对应快捷方式即可。

## 功能总览

- **三个完全独立的窗口**：各自拖动、各自记忆位置，互不影响
- **时钟窗口**：数字模式（时:分:秒 + 日期星期，12/24 小时制）与表盘模式（完整 60 格刻度、1~12/罗马数字、三档表盘大小、三种指针颜色、秒针平滑扫动），点 ☰ 打开设置面板
- **便签窗口**：多条便签新建/编辑/删除/5 色切换，📌 单条置顶，删除后 5 秒内可撤销，显示更新时间戳
- **B站粉丝窗口**：涨粉/掉粉分项（标注数据日期）、总粉丝数、今日净变化、本地凭证管理、10 分钟自动刷新
- **托盘常驻**：显示/隐藏三个窗口、始终置顶开关、透明度调节（60%~100%）、退出
- **位置记忆**：三窗口分别保存 x/y，越界自动回主屏
- **单实例**：重复启动会唤起已运行的窗口，不会开第二套进程
- **性能**：窗口隐藏时自动暂停时钟刷新

## 常见问题（FAQ）

**双击 exe 报错 `Invalid file descriptor to ICU data received` / 闪退？**

这不是应用的问题。如果你是从 **WorkBuddy、VS Code、Cursor 等 Electron 应用的内置终端或文件预览面板**里启动 exe，进程会继承 `ELECTRON_RUN_AS_NODE=1` 环境变量，导致 exe 被迫以 Node 模式运行而初始化失败。

解决办法：把 exe 放到任意文件夹，用**资源管理器双击**运行（或创建桌面快捷方式），即可正常启动。

**便携版双击后 8 秒左右才出现窗口？**

便携版单文件 exe 每次启动要先自解压到临时目录，首次或机械盘上会慢几秒，属正常现象。想秒开就用安装版（Setup）。

**粉丝窗口提示「SESSDATA 无效或已过期」？**

SESSDATA 会随 B 站登录态过期（退出登录、改密码、长时间未用都可能失效）。重新按上面步骤复制一次，点 ☰ → 重新粘贴即可。

## 已知限制

- **粉丝分项数据不是「今天」的**：B 站创作中心为 T+1，次日中午才出前一天数据；「今日净变化」只有净值、且从当日首次采样起算
- 创作中心接口属 B 站内部接口，若 B 站改版导致字段变化，分项数据可能拿不到（届时窗口会显示错误提示，公开接口的总粉丝数与今日净变化仍可用）
- 无边框透明窗口在个别旧显卡驱动/远程桌面下可能显示黑底（Electron 已知问题）
- 便签撤销仅 5 秒内有效，超时永久删除
- 时钟无时区设置
- 运行中拔掉副屏不会实时迁移窗口，重启后自动修正
- exe 未签名，首次运行 SmartScreen 可能提示"未知发布者"，点"仍要运行"即可
